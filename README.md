## О проекте

**AgroPulse** — веб-приложение для автоматизации работы с финансовой отчётностью и ESG-показателями предприятий агропромышленного комплекса.

Система позволяет:

- загружать и хранить финансовые отчёты в формате XML;
- рассчитывать финансовые коэффициенты и формировать аналитические выводы;
- вести учёт ESG-показателей;
- управлять жизненным циклом отчёта (от загрузки до утверждения);
- формировать печатную форму и экспорт в PDF;
- вести журнал аудита действий пользователей.

Проект разработан на примере предприятия **АО «МПБК Очаково»**.

## Функциональные возможности

### Роли пользователей

| Роль | Возможности |
|------|-------------|
| **Администратор** | Управление сотрудниками, просмотр отчётов, журнал аудита |
| **Оператор данных** | Загрузка отчётов, ввод ESG-показателей, утверждение к анализу |
| **Финансовый аналитик** | Расчёт показателей, анализ, комментарии, утверждение отчёта |

### Жизненный цикл отчёта

1. Загружен
2. Добавлен новый документ
3. Утверждён к анализу
4. Проведены расчёты
5. Добавлены комментарии
6. Одобрен

### Основные модули

- **Аутентификация и регистрация** — вход в систему, регистрация компании
- **Управление пользователями** — создание и редактирование сотрудников
- **Финансовые отчёты** — загрузка XML, просмотр данных, замена файла
- **Финансовый анализ** — расчёт коэффициентов, графики, рекомендации
- **ESG-показатели** — ввод и хранение экологических, социальных и управленческих метрик
- **Печать и PDF** — формирование отчёта для печати и экспорта
- **Аудит** — журналирование действий пользователей

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL репозитория>
cd AgroPulse
```

### 2. Настройка базы данных

Создайте базу PostgreSQL и укажите параметры подключения в `src/main/resources/application.yaml`:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5434/postgres
    username: postgres
    password: pass
```

Миграции Liquibase применяются автоматически при старте приложения. Демо-данные (компания, пользователи, значения ESG) загружаются из `src/main/resources/db/seed/demo-data.sql`.

### 3. Запуск приложения

```bash
./mvnw spring-boot:run
```

Приложение будет доступно по адресу: **http://localhost:8080**

## Структура базы данных

Основные таблицы:

- `companies` — компании
- `users` — пользователи
