# AgroPulse

<p align="center">
  <img src="src/main/resources/static/images/icon.svg" alt="AgroPulse" width="120">
</p>

**AgroPulse** — веб-приложение для работы с финансовой отчётностью и ESG-показателями предприятия. Система принимает бухгалтерские отчёты в XML, считает финансовые коэффициенты, хранит ESG-показатели и ведёт отчёт от загрузки до утверждения.

Проект сделан как выпускная квалификационная работа РГАУ-МСХА им. К. А. Тимирязева на материалах АО «МПБК Очаково».

## Функциональность

**Администратор:**
- Управление сотрудниками.
- Просмотр отчётов.
- Журнал аудита.

**Оператор данных:**
- Загрузка финансовых отчётов в XML.
- Ввод ESG-показателей.
- Утверждение отчёта к анализу.

**Финансовый аналитик:**
- Расчёт финансовых коэффициентов.
- Просмотр графиков и рекомендаций.
- Комментарии к отчёту.
- Утверждение готового отчёта.

Отчёт проходит шесть состояний: загружен, добавлен новый документ, утверждён к анализу, проведены расчёты, добавлены комментарии, одобрен.

Из утверждённого отчёта можно собрать печатную форму и PDF.

## Требования

- Java 21. Maven Wrapper включён в репозиторий: `./mvnw`, на Windows — `mvnw.cmd`.
- PostgreSQL. Адрес базы задаётся в `application.yaml`. В тестах Testcontainers использует образ `postgres:18.3`.
- Для тестов нужен Docker: контейнер с PostgreSQL поднимается сам.
- Для скачивания PDF заранее нужен Chromium для Playwright. Как его поставить, описано ниже. Без него остальное приложение запускается.

## Запуск

Создай базу PostgreSQL и укажи подключение в `src/main/resources/application.yaml`:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5434/postgres
    username: postgres
    password: pass
```

Миграции Liquibase применяются при старте. Демонстрационные данные загружаются из `src/main/resources/db/seed/demo-data.sql`.

```bash
./mvnw spring-boot:run
```

Тесты:

```bash
./mvnw test
```

### PDF

Скачивание PDF нужно только для выгрузки отчёта. Вход, отчёты, расчёты и ESG работают без него.

Playwright не использует обычный Chrome. Ему нужен свой Chromium, его в репозитории нет. Один раз из корня проекта:

```bash
./mvnw exec:java -Dexec.mainClass=com.microsoft.playwright.CLI -Dexec.args="install chromium"
```

Команда скачивает браузер в кэш Playwright. После этого, когда приложение уже запущено на http://localhost:8080, кнопка экспорта открывает печатную страницу отчёта и сохраняет её в PDF.

## Структура проекта

```text
src/main/java/ru/ochakovo/agropulse
├── config       # Конфигурация приложения, безопасности и PDF
├── security     # Аутентификация и роли
├── http         # Страницы и обработка ошибок
├── service      # Отчёты, расчёты, ESG и PDF
├── entity       # Сущности JPA
├── repository   # Доступ к данным
├── dto          # Объекты форм и ответов
├── mapper       # MapStruct
├── querydsl     # Сгенерированные запросы QueryDSL
├── listener     # Слушатели событий
└── util         # Общие утилиты

src/main/resources/templates     # Страницы Thymeleaf
src/main/resources/db/changelog  # Миграции Liquibase
docs/examples                    # Примеры XML и PDF
```
